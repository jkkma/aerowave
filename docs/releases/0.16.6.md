# Aerowave 0.16.6

When a station gives up and the backup folder takes over, Next and Previous
now step through the backup folder. Next used to stop playback there, and
Previous could jump back to a track from an earlier, unrelated folder
shuffle; it now returns to the backup track that played before.

A dropped station resolves its own address again from the second reconnect
attempt. Every reconnect used to reuse the address the station's redirects led
to when it started, so a station behind a load balancer or a token redirect
could not recover once that address stopped answering, and fell back to the
backup folder. A station found to be no longer HLS on reconnect now plays
through the ordinary path instead of hls.js.

## Validation and package

Source validation passed 501 frontend tests, 239 Rust core tests and 44
repository-checker tests. Coverage includes stepping through a backup
fallback, resolving a station again on reconnect, and a station leaving HLS
on desktop and Android.

The Windows x64 portable ZIP retains settings in its adjacent `data` folder;
Scoop persists that folder across updates. The executable is not code-signed.
Package hashes and completed native Windows validation are recorded in the
published release notes. Automated playback checks establish decoding and an
advancing playhead, not physical speaker audibility.
