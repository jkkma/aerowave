# Aerowave 0.16.5

Pausing a radio station now stays paused. A reconnect already waiting on its
timer, a stream probe or a play request is retired at the moment of the pause,
so a recovery that was in flight can no longer start the station again behind
your back. Resuming still rejoins the live broadcast.

Recent now shows saved stations as they are today. After a station is renamed
or given a new stream URL, its Recent entry plays the edited address rather
than the one recorded when it last played, and history entries that an edit
makes identical appear once.

Narrowing Browse by country keeps a selected genre and its count even when
that genre is not among the two hundred busiest tags there. The tally is not
filtered by the selection, so the other genres keep their own counts.

A station that answers a raw ICY connection with a web page or JSON rather
than audio is now reported as down, full or moved, as the ordinary HTTP path
already did, instead of failing later as an unsupported format. Stream
addresses written with a bracketed IPv6 literal now connect on that path too.

## Validation and package

Source validation passed 496 frontend tests, 239 Rust core tests and 44
repository-checker tests. Coverage includes paused recovery races,
Recent entries after station edits, bounded genre selection, and the
production Shoutcast probe and relay paths.

The Windows x64 portable ZIP retains settings in its adjacent `data` folder;
Scoop persists that folder across updates. The executable is not code-signed.
Package hashes and completed native Windows validation are recorded in the
published release notes. Automated playback checks establish decoding and an
advancing playhead, not physical speaker audibility.
