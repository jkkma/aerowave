# Aerowave 0.16.10

## Desktop station playback

- When a PLS, M3U, or ASX playlist lists multiple streams, Aerowave tries the
  next entry if an earlier one cannot be opened.
- HLS manifests still reach the HLS player when a playlist link redirects to
  a URL with no file extension and the server sends a generic content type.
- Authenticated HLS variants can load their relative audio segments and keys
  with the variant's credentials on the same origin. HLS Content Steering
  can switch to a backup CDN declared through the steering playlist link.
- Testing a station in the editor leaves the current Now Playing title and
  Windows media controls alone. If playback cannot recover, the player shows
  the broadcaster's error when available.

## Browse and saved stations

- Country and genre choices remain selectable when a partial tally has not
  counted them. Counts shown with a plus sign are lower bounds.
- Browse recognizes alternate submissions for the same stream across searches
  and restarts. Saved stations keep the submitted tuning address.

## Validation and Windows package

The release passed 537 frontend tests, 44 repository-checker tests, 265 Rust
core and integration tests, 15 network adapter tests, 10 network runtime
fixtures, and 14 directory fixtures. A live directory check also passed.
The Windows build produced an x64 executable and NSIS installer. The extracted
portable package reported 0.16.10 and played FIP and France Inter HLS with
advancing playheads in WebView2. Physical speaker output was unverified.

The Windows x64 portable ZIP keeps settings in the adjacent data folder.
Scoop persists that folder across updates. The executable is unsigned.
