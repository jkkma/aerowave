# Aerowave 0.16.8

## Windows fixes

- Public radio streams stay on public network routes through redirects,
  playlists and legacy Shoutcast connections. They connect directly without
  system proxies, so networks that require an outbound proxy may be unable to
  play them. Explicit local stations can still play through approved local
  routes.
- HLS playlists can use variables in stream and segment addresses while
  retaining the same destination checks.
- Station saves validate stream addresses and setup size. Restore preserves
  the original settings file if the previous setup cannot be exported as a
  backup.
- A settings refresh preserves pending changes, including when Windows reports
  that it disabled startup.
- A failed media load can consume only one retry. A late failure from a
  replaced connection leaves the current attempt playing.
- Folder status follows the current selection and alarm draft.

## Validation and package

The Windows x64 portable ZIP was tested from its own settings folder. WebView2
reported version 0.16.8 and decoded FIP with an advancing playhead at
`readyState 3`. Source checks passed 523 frontend tests, 253 Rust tests and
the repository checks.

The ZIP keeps settings beside the executable in `data`. Scoop persists this
folder across updates. The executable is unsigned.
