# Aerowave 0.16.11

## Frontend accessibility and WebView modernization

- **Native modal dialogs and controls:** The ringing alarm overlay now uses a
  native top-layer `<dialog closedby="none">` with `autofocus` on Dismiss and
  scroll containment under open modal dialogs. Alarm cards and Settings
  toggles use native `<input type="checkbox" switch role="switch">` controls
  with explicit labels, and editor form validation marks invalid fields with
  `aria-invalid="true"`.
- **Keyboard, IME, and motion safety:** Search and modal name inputs guard
  `Enter` submission against active IME composition (`isComposing` / `keyCode
  229`). Decorative animations, ring pulses, and top-layer `@starting-style`
  transitions run only when reduced motion is not requested.
- **OS text scaling and high contrast:** Declared dark `color-scheme` and
  Android `text-scale` metadata, replaced fixed root pixel font sizing and
  global `user-select: none` with relative `rem` sizing, added high-contrast
  scrollbar tokens and `@media (forced-colors: active)` support, and
  structured `styles.css` into explicit cascade layers.
- **Lazy HLS loading and idle efficiency:** `vendor/hls.min.js` is now loaded
  lazily on the first HLS stream instead of blocking initial startup. Hidden
  tab panes receive `hidden` and notify the 3D orb render loop alongside
  `IntersectionObserver` and `content-visibility: auto`.
- **Stricter CSP and DOM hygiene:** Removed `'unsafe-inline'` from `style-src`
  and added `object-src 'none'`, `base-uri 'none'`, `frame-ancestors 'none'`,
  and `form-action 'self'` to `tauri.conf.json`.

## Validation and Windows package

The release passed 543 frontend tests, 44 repository-checker tests, and 265
Rust core and integration tests. The Windows build produced an x64 executable
and NSIS installer. The extracted portable package reported 0.16.11, played
both FIP MP3 (`readyState` 3, advancing 1.017s) and lazily loaded FIP HLS
(`readyState` 4, advancing 1.013s) in WebView2, verified zero CSP violations or
runtime console errors, and verified native `<dialog>` focus management on the
ringing overlay. Physical speaker output was unverified.

The Windows x64 portable ZIP keeps settings in the adjacent data folder.
Scoop persists that folder across updates. The executable is unsigned.
