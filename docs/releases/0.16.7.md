# Aerowave 0.16.7

Browse now plays and saves the address a station was submitted under, rather
than the address radio-browser's checker last reached. That second address can
expire or change: SBS Power FM's carried a token that had already lapsed, so
Listen failed while the station itself was fine, and laut.fm's changes with
every directory check, so a saved station stopped showing as saved the next day
and could be saved twice. Stations saved by earlier versions still show as
saved. Newly saved stations can also recover missing artwork from the
directory, which looks stations up only by their submitted address.

Changing a Browse dropdown now waits a moment for the next change before it
searches. Arrowing through the country list runs one search instead of one per
key press, each with a station count of up to about six megabytes. Pressing
More during that pause runs the new search rather than paging the old one. A
dropdown loading its counts keeps keyboard focus instead of dropping it.

The directory client now talks only to radio-browser's own mirrors, and follows
redirects only between them over HTTPS. A genre used as a saved station's tag
fits the station editor's 24 characters, and the country and genre lists sort
the way people expect, so Türkiye no longer comes after Tuvalu.

## Validation and package

Source validation passed 511 frontend tests, 242 Rust core tests and the
repository checks, along with the directory client's retry fixtures and a live
check against the public directory. Coverage includes keeping the submitted
address, recognising older saves, letting a dropdown settle before it searches,
keyboard focus while counts load, and mirror names outside the directory's
domain.

The Windows x64 portable ZIP retains settings in its adjacent `data` folder;
Scoop persists that folder across updates. The executable is not code-signed.
Package hashes and completed native Windows validation are recorded in the
published release notes. Automated playback checks establish decoding and an
advancing playhead, not physical speaker audibility.
