# Aerowave 0.16.12

## Desktop radio playback

- Changing the volume while a station connects takes effect when audio starts.
  Reconnects also respect the selected volume, including zero.
- When a playlist offers several streams, the player tries the next one if
  the first sends empty audio, stalls before sending audio, or supplies an
  invalid ICY metadata interval.
- An extensionless station link can serve HLS, M3U, PLS or ASX with a generic
  content type. The player recognizes these playlists from their contents and
  keeps the original audio bytes when the endpoint serves a stream.
- If a reconnect switches to HLS, the current HLS song and bitrate take
  precedence over late metadata replies from the earlier connection.
  Three consecutive failed or titleless polls end background polling.
- A failed station save keeps its error visible even if an editor stream test
  finishes afterwards.

## Recent stations and Browse

- Next and Previous can traverse the entire Recent list as played stations
  move to the top. Listening to a saved station records the selected station,
  including when another saved mount differs only in path capitalization.
- Submitting a search again refreshes its filter counts. Country and Genre
  each become usable as their lists arrive. A selected genre outside the
  directory's top 200 keeps its name when its global count is unknown.
- Keyboard focus stays on the same station control when loading More replaces
  a row with a higher-voted submission. Equivalent root addresses with a query
  share a directory identity, including stations saved by older versions.

## Windows package and verification

The extracted Windows x64 portable package played FIP MP3 and France Inter
HLS in WebView2. Both playback clocks advanced by more than a second.
An extensionless PLS with an empty first stream played its backup at the
0% volume selected during connection. Next reached three consecutive Recent
stations, including two with case-sensitive mount names. The audio element
was muted during these checks.

All 557 frontend tests, 44 repository-checker tests, 267 Rust core and
integration tests, and 16 network adapter tests passed. The network and
directory runtime fixtures also passed.

The unsigned portable ZIP keeps settings in its adjacent data folder. Scoop
preserves that folder across updates.
