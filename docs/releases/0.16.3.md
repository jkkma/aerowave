# Aerowave 0.16.3

This Windows x64 release pauses the orb and animated backdrop while the window
is minimized or hidden in the tray, including when Aerowave starts in the tray.
Restoring the window resumes the visuals smoothly without replaying the time
spent hidden. A visible window continues animating when it loses focus.

Audio playback, volume fades and alarm scheduling remain active while the
visuals are paused. A scheduled alarm restores the window and resumes rendering.
Window visibility reads run on the UI thread without blocking the alarm clock.

## Validation

Local checks passed 455 frontend tests, 234 Rust core tests and 44 repository
checker tests. The optimized Windows application and NSIS installer built
successfully. The portable ZIP passed member, CRC, x64 binary and version checks.

The extracted ZIP launched as 0.16.3 using isolated portable settings. Native
Windows checks confirmed zero WebGL draws and paused backdrop animations while
minimized or in the tray, with local audio continuing to decode at readyState 4.
A scheduled folder alarm restored the tray window and started decoded playback.
These checks do not establish physical speaker output or sleep/wake behavior.
